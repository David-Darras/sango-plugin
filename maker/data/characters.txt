# The characters and the trainers to add to the maps.
#
# [map] starts the characters of a map. Then one character on each line:
#
#   model, x, z, height, facing, script N
#   model, x, z, height, facing, trainer TRAINER[, sight N]
#
#   model     the look of the character (lib/include/overworld/constant/model.h,
#             without the k: kYoungster is Youngster)
#   x, z      the position in tiles: stand on the tile, then read Tile X
#             and Tile Z in the menu (Overworld > Location)
#   height    the height: Height in the same page
#   facing    Up, Down, Left or Right
#   script N  the script when the player talks to the character (story.txt:
#             33000 to 33999)
#   trainer   a trainer of the game (the names of trainers.txt). The
#             character battles the player like the trainers of the game.
#   sight N   the number of tiles that the trainer sees (1 to 10, 3 if you
#             do not give it)
#
# 128 characters at most, on all the maps. A map shows 32 characters at most.
# Change the positions: put the characters on tiles where the player can walk.
