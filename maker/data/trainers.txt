# The trainers.
#
# [trainer]: the name of a trainer of lib/include/battle/constant/trainer.h, or
# its number. Then the values of the trainer.
# [new class Name, Class]: a new trainer class (64 at most). It has the data of
# the class after the comma (Youngster if you give none), then:
#   title        = the title in the battle ("Warden Joe")
#   overworld    = the character on the map (lib/include/overworld/constant/model.h)
#   picture      = the 2D picture of this class
#   introduction = the introduction of the battle of this class (3D model, effect)
#   music        = the music of the sight of this class
# Then use `class = Name` for a trainer.
# [new Name]: a new trainer (100 at most). It takes an empty trainer of the game
# and has this name. Use the name in characters.txt (`trainer Name`) and in
# story.txt (`battle trainer Name`). The values of the trainer:
#   format  = Single, Double, Triple, Rotation or Horde
#   name    = the name in the battle
#   ai      = Casual, Competitive, Strategist (one or more)
#   items   = the items that the trainer uses (4 at most)
#   money   = the prize money (the game multiplies it by the level)
#   class   = the class of the trainer: Youngster, Lass, Team Flare... (the list is
#             in lib/include/battle/constant/trainer_class.h). The class gives the
#             title, the 2D picture, the 3D model and the music of the trainer.
#   model   = a 3D model of Pokémon X and Y in the battle: Sycamore, Lysandre,
#             Flare Admin Male, Flare Admin Female, Aliana, Xerosic, Flare Grunt
#             Male, Flare Grunt Female, Celosia, Bryony, Mable, Az, Lysandre Final.
#             The files are in sango/trainer_model (tools/export_xy_trainer_models.py).
#   pokemon = one Pokémon of the team (6 at most), with its values:
#             level N, item X, ability X, nature X, form X, ivs N,
#             evs HP/Atk/Def/SpA/SpD/Spe, moves A/B/C/D, shiny
