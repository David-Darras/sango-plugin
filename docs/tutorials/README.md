# Tutorials

Each tutorial is a short procedure with code that you can copy.
Do the tutorials in order the first time. Later, use them as a reference.

Before you start, build the plugin one time:
[Getting started](../getting-started/01-install-the-tools.md).

| # | Tutorial | You learn to |
|---|---|---|
| 1 | [Create your ROM hack](01-create-your-rom-hack.md) | Make your own product and build it. |
| 2 | [Add a menu page](02-add-a-menu-page.md) | Show your own options in the menu. |
| 3 | [Add a hook](03-add-a-hook.md) | Replace a function of the game. |
| 4 | [Add a move](04-add-a-move.md) | Make a new move with its data and its effect. |
| 5 | [Add an ability](05-add-an-ability.md) | Make a new ability. |
| 6 | [Make a move animation](06-make-a-move-animation.md) | Change an animation or make a new one. |
| 7 | [Change the wild Pokémon](07-change-wild-pokemon.md) | Choose the wild Pokémon of each map. |
| 8 | [Change the trainer teams](08-change-trainer-teams.md) | Give new Pokémon to the trainers. |
| 9 | [Write an overworld script](09-write-an-overworld-script.md) | Add a character that talks and gives items. |
| 10 | [Replace models](10-replace-models.md) | Change the look of the player and of the Pokémon. |
| 11 | [Change items and shops](11-change-items-and-shops.md) | Change the data of items and the stock of a Poké Mart. |
| 12 | [Add a new Pokémon](12-add-a-new-pokemon.md) | (coming soon) |

## Conventions of the tutorials

- `myhack` is the name of your product. Use your own name.
- The code is for Alpha Sapphire v1.4.
- Each tutorial gives the files to change and the code to add.
- After each tutorial, build with `make myhack` and test in the game.
